# Student Grading Program

Overview

A simple Python program to assign grades to 2 students based on their percentage marks using nested if–else statements.

 Features

* Input student names and marks (0-100) with validation
* Assign grades: A+, A, B+, B, C, D, F
* Display student name, marks, a Sample Output

OUTPUT
EWS has scored 85% → Grade: A
Bob has scored 35% - Grade: F
